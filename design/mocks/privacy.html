Privacy

void omnibus counts a few named events as daily totals. It does not record who you are, keeps no cookie or local storage, and loads nothing from another company.

What is counted

Totals per day, nothing per person
EventCounted when
page_viewA page was opened.
week_openedA week's record was read to its last line.
episode_startedAn episode began playing.
episode_completedAn episode reached its final 30 seconds.
source_openedA link on a sources page was followed.
correction_submittedA correction was sent.

Each count has a daily ceiling, and anyone can send one, so a sudden spike is read as suspect rather than as an audience.

The forms

The feedback form and the correction form send the text you type and the page you sent it from. The server stores them with the time they arrived and nothing else. Please leave out your name, email and other personal details.

Your connection

Every page, script, style, font and video comes from this site. To stop abuse, the server limits how many requests one network can make in a short time. For that it uses your IP address (for IPv6, only its network part) while answering: Cloudflare keeps a short-lived count in memory, and void omnibus never stores or logs the address. Cloudflare, which hosts the site, still handles your IP address to deliver it, as any host does.

One exception: if one IP address sends more than 30 requests to voidvision.org sites in 10 seconds, Cloudflare's firewall blocks it for 10 seconds and records each blocked request (the address, the page asked for and the browser's user agent) in a security log that Cloudflare keeps for a limited time. That log is used only to see and stop abuse.

Retention and deletion

Daily totals are kept indefinitely; a total identifies no one. Feedback and correction text is kept for 90 days, then deleted automatically. The database can restore itself to any moment in the last 7 days, so deleted text can remain in that window for up to 7 more days.

To have something you sent deleted sooner, describe it well enough to find (the page and roughly when) through the feedback form on the home page.
