`main` on `aacrit/omnibus` is now branch-protected: required status checks `gate` and `studio-full` (strict, so a branch must be caught up before merge), no force pushes, no deletions, admins may bypass (the founder; rule 1's enforcer stays the CI job itself). `studio-full.yml` gained a rule 10 declaration (owner Forge, `kill_after_idle_days: 30`, `heartbeat_url: n/a (not declared)`, same convention as the 2026-11-12 release entry below), a `permissions: {issues: write}` block, and a failed-nightly-run step that opens or updates an issue labelled `studio-red`, the same shape as `verify-production.yml`'s `prod-red`.
