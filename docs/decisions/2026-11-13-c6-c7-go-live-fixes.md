# 2026-11-13: C6/C7 go-live fixes

On re-review of cap/c6-c7. An R2 error keeps only its status and S3's error code, never the body, and the run's report and pool copy are scrubbed of every secret's value (the R2 key id and account id included) before they reach an artifact, which a public repo makes public. `--airs-on` must be a real YYYY-MM-DD date; without one a pin lapses 60 days after it was made (`expires_on`), and a run deletes pin requests whose window (air date plus 30 days, or the expiry) has passed. The run writes the index only over the version it read (If-Match on R2's S3 API); on a lost race it re-reads, merges what the other writer added (a backfill's items, a pin), re-applies the pin requests, sweeps again and retries, at most 5 times, and otherwise fails without overwriting. The weekly reconcile deletes an unindexed media or evidence object only when R2 lists it as more than an hour old.
