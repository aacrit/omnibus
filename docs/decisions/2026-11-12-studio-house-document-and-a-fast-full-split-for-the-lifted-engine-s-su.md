# 2026-11-12: studio/house/document/, and a fast/full split for the lifted engine's suite

PR omnibus#10's gate failed `studio-test`: `studio/engine/maps.py` reads `design/tokens.css` for its palette, and three tests (`test_e15.py`, `test_render.py`, `test_a40_title_sequence.py`) read `design/brand-kit/*` directly; both are document's own design files, never transplanted in E2 (docs/TRANSPLANT-document-engine.md). Fix: those files (document's `tokens.css`, `brand-kit/{motion.py,watermark.svg,logomark.svg,watermark-youtube.svg,wordmark.svg}`) are lifted unchanged into `studio/house/document/`, each with a provenance header, and every lifted module or test that needs one reads it through one constant, `studio/engine/house.HOUSE_ROOT` (net-new, not from document). Omnibus's own `design/tokens.css` is untouched: the two never merge, and an omnibus-specific studio palette is a later (E3+) ticket. `maps.py`'s one line (`TOKENS = ...`) and three tests' path literals are the only edits; both files it maps to are the same, unchanged otherwise.

Measured locally (document-work's pinned venv, this laptop, so CI on Linux may differ): the full suite (`studio/tests`, ~2,560 cases) took 20-22 minutes, which is too slow for a per-commit gate. `aswas` (`test_a0_show_as_was.py`), `clips` (`test_r11_clips.py`), `pages` (`test_pages.py`), `disclosure` (`test_a56_disclosure.py`), `counts` (`test_counts.py`) and `maps` (`test_maps.py`, `test_a56_map_credit.py`) together are 597 cases in 90s: none of them need the session-scoped `rendered`/`plan` fixture (a real small render). `render` core (`test_render.py` alone: ~4 min), `layers`/`stems` (82s for 54 cases) and the titles/narrator/score audio checks all build or measure real media and are slow; they stay out of the per-commit gate and run only in the new `.github/workflows/studio-full.yml`: on every pull request (always reports, so branch protection can require it without blocking a PR that never touches `studio/**`) but only executes `pytest studio/tests` when `studio/**` changed, on push to `main`, or nightly (07:17 UTC).
