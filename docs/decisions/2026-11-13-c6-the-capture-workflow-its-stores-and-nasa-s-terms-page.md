# 2026-11-13: C6: the capture workflow, its stores and NASA's terms page

`.github/workflows/capture.yml` runs `scripts/capture/run.mjs` at 05:23, 13:11 and 21:41 UTC and on dispatch (25 minutes, concurrency group `capture`; rule 10: owner Studio (omnibus), kill after 21 idle days, heartbeat `https://omnibus.voidvision.org/api/capture/heartbeat`). A run lists every source, selects by relevance and the always-capture channels (a selected White House locator brings its Commons upload), keeps fetch-time evidence for each new item and, when its verdict is ok, a <=480p proxy (`scripts/capture/proxy.mjs`: Commons 480p or 360p transcodes and 854 px thumbnails, the DVIDS, NASA and VOA adapters' small files as `proxy_url`, a CDC or NOAA page's own still), plans every put through `scripts/lib/capture-store.mjs`, commits puts, then the index, then the sweep's deletes, writes the weekly pool once per issue, and writes `capture/heartbeat.json` last. A lister that fails alone is reported; a run where no lister answered, or a store write that fails, fails the job, and a failed scheduled run opens or updates the `capture-red` issue, also labelled `prod-red` for the weekly maintainer. Secrets reach only their steps: `CLOUDFLARE_API_TOKEN` the R2 step, `DVIDS_API_KEY` the capture steps (missing: DVIDS skipped with a notice). Without the token the store is a directory kept as the run's artifact for 14 days; artifacts on a public repo are public, so it holds only public-domain and Creative Commons proxies, and editorial-use items are kept as URL and evidence (`artifactMayHoldMedia`). `node scripts/capture-r2.mjs --root <artifacts>` backfills them through planPut. The Worker reads the heartbeat through the R2 binding `CAPTURE` (bucket `omnibus-capture`) and answers 503 after 30 hours; `verify-production.yml` checks it once the repo variable `CAPTURE_R2_ENABLED` is `true`. The bucket is created once with the token: `npx wrangler r2 bucket create omnibus-capture`. CoS decision (coordinator relay, 2026-11-13): `www.nasa.gov` joins the fetcher's allowlist so a captured NASA item keeps NASA's media usage guidelines (`https://www.nasa.gov/nasa-brand-center/images-and-media/`) as its governing terms page; NASA is a federal publisher, inside the founder's footage policy, and the page is read only, never a media source.
