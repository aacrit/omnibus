# 2026-11-21: T5, refused sources: C-SPAN absolutely, Kanal13 and VTV by default, any foreign state's PD mark; the uploader read on every transfer (builder, from show bible v2 section n)

`sources.mjs REFUSED_SOURCES` refuses an item whose own source record names one of these sources. The record is its Artist and Credit, its file page's `|author=` and `|source=` lines and licence templates, its categories and its uploader. A title or description is not read, because there the name is a subject. **C-SPAN** (the Duckworth and Cao hearing video, which Commons tags `{{PD-CSPAN}}`). Section n reads "refused unless the record shows a chamber's own floor feed". The builder's call: that exception is met by taking the floor feed from the chamber itself (senate.gov or house.gov, through the federal-page adapter, where C-SPAN is not the source), and never by trusting a C-SPAN-credited copy that claims to be one. Such a copy also carries C-SPAN's bug, which the agency-bug rule refuses. So any item naming C-SPAN is refused. **Kanal13** (the CC BY Shenzhen arrival uploads that look like agency pool) and **VTV** (Venezolana de Televisión, marked "Public domain") are refused by default. Lifting either needs a ruling recorded here, never a pin. **A foreign state's official-works mark** ("PD Venezuela official", `{{PD-VenezuelaGov}}`, `PD-RU-exempt`) is not a basis until that state's terms are reviewed. A denied host named only in a file page's `|source=` now refuses the file too. **Uploader.** Every Commons transfer records its first uploader (the name from the upload history; the age and edits as before for an own-work claim), and a transfer whose uploader cannot be read is a laundering suspicion. The `licence-allowlist` lint reads the refused sources again from the stored credit and evidence.
