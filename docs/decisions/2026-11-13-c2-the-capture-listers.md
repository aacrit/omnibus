# 2026-11-13: C2: the capture listers

`scripts/capture/listers/{whitehouse,commons,dvids,voa,nasa,cdc,noaa}.mjs` are pure parsers plus a `list*({ http, now, since })` each, the HTTP injected (http.mjs's getText/getJson on Actions, a fake in tests), every item `{ source, id, url, title, description, published_at, captured_at }` with the source's own fields beside it; `published_at` is the source's own field (Commons: the upload time, with the file page's date as `event_date`; NASA: `date_created`, the only date its API gives). The default window is the last 72 hours. White House items are locators only (`locator: true`, `media_url: null`): its videos are YouTube embeds and are never downloaded; `matchCommons` pairs each with its Commons upload by a shared YouTube id, else by at least 80% title overlap with the upload between a day before and a week after the post. Commons reads six video categories whose names were read from Commons's own category search on 2026-11-13. DVIDS searches by publish date with `DVIDS_API_KEY` from the environment; the key is only in the request URL, never in an item, and errors are redacted. VOA keeps its own article pages and drops items its feed credits to a wire. `scripts/capture/listers/wayback.mjs` locates and dates pages of the hosts C0 recorded as refusing (war.gov, state.gov, noaa.gov) through the CDX index and dated captures; it throws before any request for a media URL (by extension, media host or a Wayback media flag) or for a host that answers us, and is never a media source.
