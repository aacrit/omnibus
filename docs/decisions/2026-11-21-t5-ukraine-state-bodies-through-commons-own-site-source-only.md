# 2026-11-21: T5, Ukraine's state bodies through Commons: the body's template, its authorship and a source on its own site (builder, from show bible v2 section n)

president.gov.ua answers 403 to our honest request, and that is never worked around, so the four bodies of section n (the SSU, the Office of the President, the Kyiv City State Administration, SES Ukraine) are reached only as Commons transfers, through the `uastate` adapter. A file passes as a body's release only when its own Commons record shows all of it: Commons reads its licence as CC BY 4.0; the file page carries that body's licence template (`{{Ssu.gov.ua}}`, `{{President.gov.ua}}`, `{{kyivcity.gov.ua}}`, `{{dsns.gov.ua}}`); its author is the body; and its `|source=` names a page on the body's own site, where the CC BY 4.0 terms apply. **Refused:** a picture the body posted on X, Telegram or YouTube with no page on its own site, because the site's terms do not cover it. The first case is `FlamingoKerch.jpg`, whose only source is the President's X post although Commons tags it `{{President.gov.ua}}`. A YouTube copy that also names the body's own page (the SES Komyshuvakha video) passes the body checks and is still held to the video2commons marks review. Every Commons check runs as before. The item records `released_by` and the label `RELEASED BY <body>` ("RELEASED BY THE SECURITY SERVICE OF UKRAINE"). The four bodies are listed as the CoS named them in section n; adding a body needs a ruling.
