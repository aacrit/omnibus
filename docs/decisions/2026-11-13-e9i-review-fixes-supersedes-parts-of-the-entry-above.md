# 2026-11-13: E9i review fixes (supersedes parts of the entry above)

On review of PR #19. The licence map reads only rights-ledger items (`rights-ledger.json`), and own-property only for the voidnews adapter; there a rights-ledger id is judged by the map alone (an id off it is refused, never read by the house regexes), and every other ledger keeps the house wording, so the writer's `studio-e4b.json` items say "Public domain", not `pd-us-federal`. CC BY-SA 1.0 is refused (no later-version clause, so it cannot enter a CC BY-SA 4.0 episode) and leaves `licences.mjs` ALLOWED_IDS. A graphic is dated by the latest date any of its data_ref's refs reads; `week:bars` beside a test card is the bars that card draws, dated by its rundown testcard's `field` (week: the latest day's print), and the Echo card's `week:bars` draws no data (spec 3.4, CoS decision) so it dates 1952. A vision entry is used only when the file on disk (hashed, cached by size and mtime), the ledger and the entry name the same sha256; the legacy `shows_violence_or_bodies` counts as the ledger's flag; needs come from every kind a picture is cited as; a missing reading is a warning only under --draft. A voicing manifest path must stay inside the film folder on every OS; words are placed after --fit-voices. A clip the ledger airs muted is refused as an archival span too. Disclosures count clips heard through spans, and `credit-disclosures-shown` refuses a final render whose E6 credits roll (typeset from the rundown's credits disclosures) lacks one: week 33's roll lacks the DoW non-endorsement line for e33-day5-pic.
